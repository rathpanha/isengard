# Isengard 0.1.4 (Linux)

First release with built-in update checking and updating. Tag, `Cargo.toml`,
and package filenames all use **0.1.4**.

## Highlights

- **Updates:** checks GitHub for a newer release at startup (at most once a
  day) and from **Isengard > Check for Updates…**. Turn the startup check off
  with `"updates": { "check": false }` in `config.json`.
  - Tarball / user-installed copies download, verify, and swap the binary,
    then offer **Restart now** (your workspace reopens).
  - `.rpm` / `.deb` installs download and verify the package, then type
    `sudo dnf|zypper|apt install …` into a terminal tab for you to run.
  - Every update is checked against a minisign-signed `SHA256SUMS`.
- Git panel: collapsible per-repository sections; Claude Suggest runs in
  parallel across repositories.

## Upgrading from 0.1.3

0.1.3 has no updater — install this version manually once (see the root
[README](../../README.md)). Later versions can update from inside the app.

## Not in this binary

- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)
- macOS / Windows installers (not shipping yet)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
