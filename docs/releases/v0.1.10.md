# Isengard 0.1.10 (Linux + macOS)

First macOS release. Tag, `Cargo.toml`, and package filenames all use **0.1.10**.

## New: macOS

- Universal build (Apple Silicon + Intel): `isengard-0.1.10-macos-universal.dmg`
  and `.tar.gz`. Requires macOS 12 or later.
- Isengard is **not notarized** by Apple (no paid developer account), so a
  browser-downloaded copy is blocked once by Gatekeeper. Either install from
  Terminal (no warning):

  ```sh
  curl -fsSL https://raw.githubusercontent.com/rathpanha/isengard/master/scripts/install-macos.sh | bash
  ```

  or open the `.dmg`, drag Isengard to Applications, then allow it in
  **System Settings → Privacy & Security → Open Anyway** (or run
  `xattr -dr com.apple.quarantine /Applications/Isengard.app`).
- The first time the Claude Agent reads your Claude Code login, macOS asks for
  Keychain access once — choose **Always Allow**.
- Releases are signed with one stable self-signed certificate, so that choice
  survives updates.

## Updating

**Check for Updates…** now updates the macOS app in place (no password, no
Gatekeeper prompt) and restarts into the new version. Linux behaves as before.

## Not in this binary

- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)
- Windows installer (not shipping yet)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
