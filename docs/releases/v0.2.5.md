# Isengard 0.2.5 (Linux + macOS + Windows)

Bug-fix release. Tag, `Cargo.toml`, and package filenames all use **0.2.5**.

## Changes

- **Git push / pull over SSH from a desktop launch.** Isengard now uses the
  `SSH_AUTH_SOCK` from your interactive shell for `push`, `pull`, `fetch` and
  `clone` (Linux / macOS). Before, an app started from the launcher missed
  agents exported in `~/.bashrc` and used the wrong SSH key.
- **Agent prompts keep inline `@file` tokens where you typed them.**
- **Linux: clicking the agent-finished notification raises the window.**

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
