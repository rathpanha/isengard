# Isengard 0.2.13 (Linux + macOS + Windows)

Tag, `Cargo.toml`, and package filenames all use **0.2.13**.

## Changes

- **Windows: fix clean-PC / v0.2.12 crash.** v0.2.12 linked the MSVC CRT
  statically; the exe started without `vcruntime140.dll` but then crashed on
  open with no dialog (GPUI/D3D). This build goes back to the dynamic CRT and
  ships `vcruntime140.dll` / `vcruntime140_1.dll` / `msvcp140.dll` beside
  `isengard.exe` in the zip. Fresh install and in-app update both place those
  DLLs next to the exe.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

If you are stuck on a broken v0.2.12 Windows install, re-run:

```powershell
irm https://raw.githubusercontent.com/rathpanha/isengard/master/scripts/install-windows.ps1 | iex
```

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
