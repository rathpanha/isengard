# Isengard 0.2.11 (Linux + macOS + Windows)

Tag, `Cargo.toml`, and package filenames all use **0.2.11**.

## Changes

- **Publish Branch.** The Git panel's Push button reads **Publish Branch** for a
  local branch with no upstream and publishes it with `git push -u`, instead of
  failing with a "needs to be published" error.
- **Language servers on bracketed paths.** Files under folders like Next.js
  `[locale]` now get their language server, so Go to Definition and Code Actions
  work there.
- **Terminal links.** URLs broken across soft-wrapped terminal rows are detected
  as one link; Ctrl/Cmd+click opens the full URL.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
