# Isengard 0.1.16 (Linux + macOS + Windows)

Patch for a hang when opening a large folder. Tag, `Cargo.toml`, and package
filenames all use **0.1.16**.

## Changes

- **Open Folder no longer beachballs** on large trees (Home, monorepos, slow
  disks). File watching now registers each workspace root immediately and
  returns; macOS and Windows use one recursive watch per root, and Linux still
  walks descendant directories off the UI thread. Opening a workspace with
  several roots uses the same path.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
