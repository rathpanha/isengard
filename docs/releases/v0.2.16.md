# Isengard 0.2.16 (Linux + macOS + Windows)

Tag, `Cargo.toml`, and package filenames all use **0.2.16**.

## Changes

- **Windows: fix crash on open.** On a PC without Bun, the "Set up Bun" dialog
  was opened before the window finished building, which panicked ("component
  window state is missing") and closed the app with no message. It now opens
  once the window is ready. This is the cause of the silent start-up crash
  seen on Windows in v0.2.12–v0.2.15 (and on any machine without Bun).
- **Windows: startup log.** The release exe writes
  `%LOCALAPPDATA%\isengard\isengard.log` (reset each launch) with panics and a
  backtrace. v0.2.14 never published (its Windows build failed to compile).

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
