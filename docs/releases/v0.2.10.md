# Isengard 0.2.10 (Linux + macOS + Windows)

Tag, `Cargo.toml`, and package filenames all use **0.2.10**.

## Changes

- **Agent chats survive a forced quit.** A chat that cannot be reopened on the
  next start (for example the editor was killed before the agent saved it) now
  stays in the chat list instead of being removed.
- **Safer settings save.** `config.json` is written atomically, so a crash mid-write
  cannot corrupt your settings or sessions.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
