# Isengard 0.2.3 (Linux + macOS + Windows)

Bug-fix release. Tag, `Cargo.toml`, and package filenames all use **0.2.3** (0.2.2 was never published).

## Changes

- **Diff view no longer jumps to the top while scrolling.** The two panes'
  scroll sync now follows only the pane you are scrolling (under the mouse,
  else the focused one), so a shorter pane's clamped position is no longer
  echoed back. Most visible on added or deleted files.
- **Agent: changing the subagent model no longer restarts the chat.** The new
  value applies the next time the agent starts.
- **Agent: rejecting a Cursor plan now stops the turn** instead of letting the
  agent keep running.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
