# Isengard 0.1.5 (Linux)

Fixes for the in-app updater and Agent chat restore. Tag, `Cargo.toml`, and
package filenames all use **0.1.5**.

## Fixes

- **Check for Updates…** now works: the menu item did nothing in 0.1.4. A manual
  check shows "Checking for updates…" straight away and then either the update
  dialog or "Isengard X is up to date". Update requests also time out instead of
  hanging on a bad connection.
- **Agent chat restore:** reopening the editor no longer cuts off the newest
  replies of a restored chat (the "N Files" summary cards were miscounted in the
  transcript list).

## Updating

0.1.4 can update itself, but its **Check for Updates…** menu item is broken —
it still finds this release on its own at startup (at most once a day), or
install 0.1.5 manually. From 0.1.5 on, the menu item works.

## Not in this binary

- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)
- macOS / Windows installers (not shipping yet)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
