# Isengard 0.1.14 (Linux + macOS + Windows)

Small agent-chat improvement. Tag, `Cargo.toml`, and package filenames all use
**0.1.14**.

## Changes

- **Tool calls collapse into one card.** Two or more tool calls in a row (with
  any thoughts between them) now show as a single card — `N steps`, or the
  running tool's title while it works — instead of one row each, so long agent
  turns no longer flood the chat. Click the card to expand the individual
  steps. It opens by itself when a step needs your permission, so Allow / Deny
  are never hidden.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
