# Isengard 0.2.4 (Linux + macOS + Windows)

Bug-fix release. Tag, `Cargo.toml`, and package filenames all use **0.2.4**.

## Changes

- **Diff / conflict view: the shorter pane no longer jitters.** When one side
  was shorter, scrolling the longer one made the shorter pane jump up and down
  by itself (most visible on the left side of a conflict). Both panes now share
  the same scroll extent; the shorter one gets empty space at the bottom.
- **Source Control: no more false “Rebase in progress”.** Git can leave a stray
  `.git/REBASE_HEAD` behind after a rebase that stopped on a conflict and was
  continued. Isengard treated that as a running rebase, showed the banner and
  disabled Pull / Push / Discard. Only a real rebase (`rebase-merge` /
  `rebase-apply`) counts now, like git itself. If you still see it on an old
  build, `git update-ref -d REBASE_HEAD` clears it.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
