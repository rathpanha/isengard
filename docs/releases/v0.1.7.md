# Isengard 0.1.7 (Linux)

One-click package updates, agent notifications, and a rounded app icon. Tag,
`Cargo.toml`, and package filenames all use **0.1.7**.

## New

- **Install updates in the app (.deb / .rpm):** **Install now** asks for your
  administrator password in a dialog, installs the package with live output,
  deletes the downloaded file, and restarts Isengard. Copy command / Open in
  terminal are still there as fallbacks.
- **Agent notifications:** when an agent run finishes (or fails) while Isengard
  is in the background, you get a desktop notification with the Isengard icon
  and a short sound.
- **Quit protection:** closing the editor while the agent is running asks first
  (Quit Anyway / Keep Working), before the unsaved-files prompts.
- **Rounded app icon** on every platform.

## Changes

- The plan usage panel no longer shows the "What's using your week" per-product
  breakdown.

## Updating

0.1.5 and later update themselves: **Check for Updates…** or the daily startup
check offers this release. The one-click install above starts working from this
version on, so updating *to* 0.1.7 from 0.1.6 still shows the old command dialog.

## Not in this binary

- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)
- macOS / Windows installers (not shipping yet)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
