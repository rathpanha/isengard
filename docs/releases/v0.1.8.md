# Isengard 0.1.8 (Linux)

Safer quitting and a terminal Ctrl+C fix. Tag, `Cargo.toml`, and package
filenames all use **0.1.8**.

## Fixes

- **Terminal:** Ctrl+C now interrupts the running process again. It was being
  swallowed as "Copy"; copying terminal text is Ctrl+Shift+C.
- **Quit protection:** closing the editor while a terminal is running a program
  (a dev server, a build, …) now asks first, like it already does for a running
  agent (Quit Anyway / Keep Working).
- **No leftover processes:** quitting stops each terminal's running program
  (SIGTERM, then SIGKILL after about a second) so servers don't keep holding
  their port after Isengard closes. Linux and macOS; background jobs started
  with `&` or `nohup` are not stopped.

## Updating

0.1.5 and later update themselves: **Check for Updates…** or the daily startup
check offers this release. On `.deb` / `.rpm` installs, **Install now** (added in
0.1.7) asks for your password, installs, and restarts Isengard for you.

## Not in this binary

- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)
- macOS / Windows installers (not shipping yet)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
