# Isengard 0.1.15 (Linux + macOS + Windows)

Bun replaces Node as the runtime for the agent, the formatter and
npm-packaged language servers. Tag, `Cargo.toml`, and package filenames all use
**0.1.15**.

## Changes

- **Bun is required.** On first launch without Bun, a **Set up Bun** dialog
  downloads Bun 1.4.4 into Isengard's own data folder (nothing is installed
  globally) and cannot be dismissed until it is installed. An existing Bun on
  `PATH` or in `~/.bun/bin` is used instead and shows no dialog.
- **Node is no longer used.** The Claude Agent adapter and npm-packaged language
  servers install with `bun add` (package cache kept in Isengard's data folder)
  and run as `bun <script>`. Existing installs keep working and start running on
  Bun by themselves — no reinstall needed.
- **Format on save uses `bun fmt`** (Prettier-compatible) for JS, TS, JSON, CSS,
  HTML, YAML and Markdown. A project's `.prettierrc` / `.editorconfig` wins;
  otherwise your tab size setting (default 2) applies. Other files still use
  their language server. If formatting fails you get a warning and the file is
  saved unformatted.
- **Per-file indentation.** Each file's indentation (tabs, or 2 / 4 / 8 spaces)
  is detected when it opens and shown in the status bar (`Spaces: 2`,
  `Tab Size: 4`). Language-server formatting now uses it instead of a fixed
  4 spaces.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.
Restart Isengard afterwards — a running agent keeps using Node until it restarts.

## Known limits

- Only the Claude Agent adapter has been run on Bun; the npm-packaged language
  servers (TypeScript, Pyright, JSON/CSS/HTML, YAML, Bash, Dockerfile, …) have
  not been tested there. If one breaks, Remove and Install it again from the LSP
  status menu and report which one.
- Windows `.cmd` shims are not moved to Bun yet.
- `bun fmt` runs on save without a timeout.
- Linux x86_64 uses Bun's standard build, which needs a CPU with AVX2.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
