# Isengard 0.2.9 (Linux + macOS + Windows)

Tag, `Cargo.toml`, and package filenames all use **0.2.9**.

## Changes

- **Cut, Copy and Paste in the file tree.** Right-click a file or folder, or use
  `Ctrl+X` / `Ctrl+C` / `Ctrl+V` (`⌘` on macOS) with the tree focused. A cut row
  is dimmed and the cut or copied row shows a scissors / copy icon until it is
  pasted. Copies never overwrite: a taken name becomes `a copy.txt`,
  `a copy 2.txt`.
- **Multi-select.** Hold `Ctrl` (`⌘` on macOS) and click rows to select several.
  Cut, Copy, Delete and drag-to-move then act on all of them. A plain click
  clears the selection. Shift range-select is not there yet.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
