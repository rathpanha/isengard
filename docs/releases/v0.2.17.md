# Isengard 0.2.17 (Linux + macOS + Windows)

Tag, `Cargo.toml`, and package filenames all use **0.2.17**.

## Changes

- **Fix: launching with a bad path.** `isengard <folder>` with a folder that
  does not exist, or a workspace file that fails to load, showed its error toast
  before the window was ready and crashed the app (the same cause as the
  v0.2.16 Windows startup fix). The open now runs once the window is up.
- **Windows: agent-done notification.** A finished or failed agent run in the
  background raises a toast and a chime. The toast shows under PowerShell's
  name and clicking it does not raise the window. New in this release, so tell
  us if it misbehaves.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
