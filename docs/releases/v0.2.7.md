# Isengard 0.2.7 (Linux + macOS + Windows)

Tag, `Cargo.toml`, and package filenames all use **0.2.7**.

## Changes

- **One window per folder.** Launching `isengard <folder>` (or a workspace file,
  or a file inside the folder) while that folder or workspace is already open
  raises the existing window instead of starting a second process. A file
  argument is opened in that window.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
