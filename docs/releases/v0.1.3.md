# Isengard 0.1.3 (Linux)

First public Linux packages that ship cleanly from CI (`.deb`, `.rpm`, binary
tarball). Tag, `Cargo.toml`, and package filenames all use **0.1.3**.

## Highlights

- Multi-root workspaces, file tree, tabs, tree-sitter editor, integrated
  terminal, Source Control, project search
- LSP via on-demand Install (not bundled in the package)
- Agent panel (Claude Agent ACP) — Install / Login, chats per folder
- File watching that skips `node_modules` / build dirs (safe for large trees)

## Install

See the root [README](../../README.md). Packages include the
`app.isengard.edtir` desktop entry and icon (Wayland-friendly).

## Not in this binary

- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)
- macOS / Windows installers (not shipping yet)
- In-panel agent switch (change agent in `config.json` if needed)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
```
