# Isengard 0.2.0 (Linux + macOS + Windows)

Cursor as a built-in ACP agent, plus Source Control polish. Tag,
`Cargo.toml`, and package filenames all use **0.2.0**.

## Changes

- **Cursor Agent (built-in):** Install app-locally like Claude
  (`…/agents/cursor/`; Cursor.app not required), pick Claude or Cursor per
  workspace (remembered on restart), switch from the header logo.
  Parameterized Model / Fast / Context / Effort, auto-allow tool permissions
  (`--force`), Plan mode with a **Build it** card (`create_plan` → Agent +
  continue). Git Suggest offers Generate + Claude + Cursor. README updated
  for the dual-agent story.
- **Source Control:** repo header truncates the branch name under width
  pressure (not the repo label); status refreshes after every agent turn end
  so Push(N) / Pull(N) clear after `git push` (`.git` is not FS-watched).

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
