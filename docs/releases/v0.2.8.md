# Isengard 0.2.8 (Linux + macOS + Windows)

Tag, `Cargo.toml`, and package filenames all use **0.2.8**.

## Changes

- **Vue and Angular.** `.vue` files and `*.component.html` are recognized, and
  opening one offers to install the language server (Volar / `ngserver`). Script
  features in Vue need TypeScript forwarding that is not wired yet, so they are
  limited.
- **About 30 more languages detected:** SCSS, Less, Prisma, Dart, Haskell, OCaml,
  Terraform, Nix, Elm, PureScript, Solidity, Perl, XML, Clojure, Erlang, Nim,
  Gleam, F#, Objective-C, LaTeX, Typst and more. Servers for Prisma, Elm,
  PureScript, Solidity, Perl and PHP install from the LSP menu; the rest use a
  server already on your `PATH`.
- Dotfiles such as `.bashrc`, `.editorconfig`, `Gemfile` and `Jenkinsfile` get
  the right language.
- Most of the new servers are untested on Bun.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
