# Isengard 0.1.6 (Linux)

Terminal and Agent panel fixes. Tag, `Cargo.toml`, and package filenames all
use **0.1.6**.

## Fixes

- **Terminal:** Tab and Shift+Tab now reach the shell, so completion works.
- **Agent:** plan usage bars no longer disappear when the usage endpoint
  rate-limits. Last numbers are saved and shown dimmed, polling backs off after
  a 429, and a "rate limited" note shows when there is nothing to display.

## Updating

0.1.5 and later can update themselves: **Check for Updates…** or the daily
startup check will offer this release.

## Not in this binary

- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)
- macOS / Windows installers (not shipping yet)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
