# Isengard 0.2.14 (Linux + macOS + Windows)

Tag, `Cargo.toml`, and package filenames all use **0.2.14**.

## Changes

- **Windows: startup log.** The release exe has no console, so a failed start
  left nothing behind. It now writes `%LOCALAPPDATA%\isengard\isengard.log`
  (reset each launch; info level, `RUST_LOG` overrides) and records panics with
  a backtrace. This does not fix the silent crash on open some Windows PCs
  still see; it is there to find the cause. If Isengard closes right after
  launch, please attach that file to an issue.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
