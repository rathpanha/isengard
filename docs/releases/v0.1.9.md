# Isengard 0.1.9 (Linux)

Two small fixes. Tag, `Cargo.toml`, and package filenames all use **0.1.9**.

## Fixes

- **Agent settings:** the popover closes on an outside click again (clicks
  inside its nested model menus no longer count as outside).
- **Approve Plan:** keeps Claude's own "No, keep planning" label, with no plan
  Preview.

## Updating

0.1.5 and later update themselves: **Check for Updates…** or the daily startup
check offers this release. On `.deb` / `.rpm` installs, **Install now** (added in
0.1.7) asks for your password, installs, and restarts Isengard for you.

## Not in this binary

- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)
- macOS / Windows installers (not shipping yet)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
