# Isengard 0.2.1 (Linux + macOS + Windows)

Windows fix release plus a Source Control refresh fix. Tag, `Cargo.toml`, and package filenames all use
**0.2.1**.

## Changes

- **Windows: no more flashing terminal windows.** Release builds are GUI apps,
  and every console program Isengard started (`git`, Bun, `go`, language
  servers) opened its own window. Open Folder flashed several, and installing
  a language server kept popping them up. All subprocesses now start with
  `CREATE_NO_WINDOW`. Not related to the app being unsigned.
- **Source Control stays current.** The panel now notices commits, pulls,
  rebases and merges made outside the app (a terminal, another tool), so a
  finished rebase no longer leaves "Rebase in progress — continue from the
  terminal" on screen. It watches `HEAD`, the index, refs and the merge /
  rebase markers in `.git`.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Known gap

- The Claude / Cursor agent process is started by the ACP SDK and does not yet
  use the same flag; if the agent panel still flashes a window on Windows,
  that is the cause.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude / Cursor Agent adapters (install from the Agent panel; login is the
  agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
