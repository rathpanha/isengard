# Isengard 0.1.12 (Linux + macOS + Windows)

First Windows release, plus agent fixes. Tag, `Cargo.toml`, and package
filenames all use **0.1.12**.

## New: Windows

- 64-bit Intel/AMD zip: `isengard-0.1.12-windows-x86_64.zip`.
- Isengard is **not code-signed** (no paid certificate), so a zip downloaded in a
  browser shows SmartScreen's "Windows protected your PC" (**More info → Run
  anyway**). Install from PowerShell to avoid it:

  ```powershell
  irm https://raw.githubusercontent.com/rathpanha/isengard/master/scripts/install-windows.ps1 | iex
  ```

  It installs to `%LOCALAPPDATA%\Programs\Isengard` (no administrator rights),
  adds a Start Menu shortcut, and puts the folder on your `PATH`.
- **Check for Updates…** updates the Windows app in place and restarts.
- This is the first build from the Windows pipeline; expect rough edges and
  please report them.

## Agent

- **Rename chat → Generate** no longer closes the dialog and renames at once. It
  shows a spinner, puts the generated title in the input box, and the chat is
  renamed only when you click **Rename**.
- **Improve prompt, Git generate message and chat-title Generate** now work while
  the agent is answering (they run on separate throwaway sessions). The chat's own
  reply is no longer at risk of being swallowed by them.

## Updating

**Check for Updates…** works as before on Linux and macOS. Windows users install
once with the command above.

## Not in this binary

- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
