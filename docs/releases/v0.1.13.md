# Isengard 0.1.13 (Linux + macOS + Windows)

Small macOS fix. Tag, `Cargo.toml`, and package filenames all use **0.1.13**.
Linux and Windows are unchanged apart from the version.

## Fixes (macOS)

- **"Agent finished" notifications show the Isengard icon.** They used to be
  sent through a script helper, which macOS credits to Script Editor. They now
  come from Isengard itself and are listed under Isengard in **System Settings →
  Notifications**. macOS asks once to allow notifications — choose **Allow**.
  (If you deny, no banner is shown; the chime still plays.)

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
