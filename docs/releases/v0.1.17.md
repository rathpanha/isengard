# Isengard 0.1.17 (Linux + macOS + Windows)

Terminal scrollback and an OpusPlan fix. Tag, `Cargo.toml`, and package
filenames all use **0.1.17**.

## Changes

- **Terminal scrollback**: mouse wheel / trackpad and Shift+PageUp/PageDown
  scroll history (10,000 lines). Selection, links and cursor follow the
  scrolled viewport; typing or pasting snaps to the bottom. Apps on the
  alternate screen or with mouse reporting still get the wheel.
- **OpusPlan Switch starts off**: opening a Claude chat pins the concrete
  Model instead of turning OpusPlan on from a flag or terminal setting.

## Updating

**Check for Updates…** updates Linux, macOS and Windows installs in place.

## Not in this binary

- Bun (downloaded on first launch)
- Language servers (install from the LSP status menu)
- Claude Agent adapter (install from the Agent panel; login is the agent’s)

## Verify

```sh
shasum -a 256 -c SHA256SUMS
# optional, with minisign installed and minisign.pub from the repo:
minisign -Vm SHA256SUMS -p minisign.pub
```
